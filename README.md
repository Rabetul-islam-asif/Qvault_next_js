# QVault - Live Academic Archive

**Live URL:** [![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge&logo=netlify&logoColor=white)](https://qvault.netlify.app/)

## Description
QVault is a curated archive of past papers, slides, and class notes. It allows students to filter resources by semester, professor, or course code instantly.

## Features
- **Question Bank**: Browse past exam papers.
- **Course Materials**: Access slides, books, and notes.
- **Faculty Hub**: Explore resources by professor.
- **Admin Dashboard**: Manage uploads and database records.
- **PWA Support**: Installable on mobile and desktop.

## Local Development

To run the project locally:

1.  **Clone the repository** (if applicable).
2.  **Run a static server**:
    ```bash
    npx serve .
    ```
3.  Open [http://localhost:3000](http://localhost:3000) in your browser.
