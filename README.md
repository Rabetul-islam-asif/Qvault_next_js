🚀 Welcome to My Code Scaffold

This is a modern, production-ready starter template I built to speed up web development using a clean, organized structure and some of the best tools in today’s frontend ecosystem. Whether you're starting a new project or experimenting with ideas, this scaffold gives you a solid foundation to build on.

✨ Technology Stack

This setup includes a powerful combination of tools and libraries:

🎯 Core Framework

Next.js 15 — App Router, server components, and production-ready performance

TypeScript 5 — Type-safe development

Tailwind CSS 4 — Fast UI building with utility-first styling

🧩 UI & Styling

shadcn/ui — Elegant, accessible components

Lucide React — Clean icon set

Framer Motion — Smooth animations

Next Themes — Simple and reliable dark mode

📋 Forms & Validation

React Hook Form — Performant forms

Zod — Type-safe schema validation

🔄 State & Data

Zustand — Lightweight global state

TanStack Query — Server state management

Axios — HTTP client

🗄️ Backend & Database

Prisma — Type-safe ORM

NextAuth.js — Authentication out of the box

📊 UI Enhancements

TanStack Table — Flexible table logic

DND Kit — Drag-and-drop functionality

Recharts — Beautiful charts

Sharp — Fast image processing

🌍 Utilities & Internationalization

Next Intl — i18n support

Date-fns — Date utilities

ReactUse — Useful collection of React hooks

🎯 Why I Built This Scaffold

To speed up the setup process for new projects

To provide a clean architecture and folder structure

To include the tools I use most often in production

To give myself a customizable, extendable foundation

To ensure strong type safety and modern UI capabilities

🚀 Getting Started
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production build
npm start


Open http://localhost:3000
 in your browser.

📁 Project Structure
src/
├── app/                 # App Router pages and layouts
├── components/          # Shared UI components
│   └── ui/              # shadcn/ui-based components
├── hooks/               # Reusable custom hooks
└── lib/                 # Utility functions and configs

🎨 Available Features
🧩 UI Components (shadcn/ui)

Includes components for:

Layout (Card, Separator, Resizable Panels, etc.)

Forms (Input, Textarea, Select, etc.)

Feedback (Alert, Toast, Skeleton, Progress)

Navigation (Breadcrumb, Pagination, Menubar)

Overlay (Dialog, Tooltip, Popover, Sheet)

Data Display (Badge, Avatar, Calendar)

📊 Data Tools

Fully dynamic tables using TanStack Table

Clean charts with Recharts

Type-safe form validation using Zod + React Hook Form

🎨 Interactive Features

Smooth animations using Framer Motion

Drag-and-drop with DND Kit

Built-in theme switching (dark/light)

🔐 Backend Integration

Authentication with NextAuth

Database operations with Prisma

API calls managed via Axios + TanStack Query

Global state handled by Zustand

🌍 Production-Ready Features

Multi-language support (Next Intl)

Optimized image handling with Sharp
